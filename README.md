# DS_Trabalho_Pratico

## Setup

###     Criando um ambiente virtual
    
    python -m venv path/to/venv
### Acessando o ambiente virtual:

#### Windows:
    ./path/to/venv\Scripts\activate
#### Linux 
    source /path/to/venv/bin/activate

### Dependências: 

    pip install -r requirements.txt

## How to Run
    python src/main.py
