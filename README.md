# DS_Trabalho_Pratico



## Criando uma venv:
| python -m venv .venv

## Entrando na venv:
#### Windows:
|       No mesmo diretório onde foi criada a venv, digite: 

        .venv\Scripts\activate

#### Linux:
|       No mesmo diretório onde foi criada a venv, digite: 

        .venv\bin\activate



## Instalando as dependências:
        | pip install -r requirements.txt

Pronto, para rodar apenas digite 

       python src/main.py
